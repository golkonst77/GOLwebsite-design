1. Общая форма: лимит пропускает одновременные отправки, доверяет первому XFF; нет Origin/JSON/общего body-read ограничителя. Защита LexRadar не покрывает этот API автоматически.

3. Доступность: контраст 14 узлов footer и 2 узлов privacy ниже AA; это находится вне hero-only тестов.
4. Один dev-only advisory braces даёт четыре high package entries; runtime audit=0. Автоматических dependency fixes не выполнялось.

Production, SMTP/Telegram, реальная аналитика, Nginx/PM2 topology/лимиты/серверный SHA и работающий build не проверялись и не менялись. Получение письма подтверждено **владельцем**, не новым тестом аудитора. Юридическая актуальность и рекламные доказательства требуют отдельной приёмки.

Локальный Lighthouse: главная Perf 80 / CLS .19, LexRadar Perf 97 / CLS 0. Это один simulated mobile run, не production метрики. Отдельные SEO-возможности и разные контакты — вопросы решения, не автоматически ошибки.

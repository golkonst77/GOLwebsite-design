## Прочие документационные материалы

Исторические SMTP/raw выводы не публикуются заново. Это явное ограничение контентного просмотра, а не проверка безопасности каждого байта архива. LOGO GOL — бренд-ресурсы, не документация текущего API; внешний статус использования не установлен.

## Опасные старые команды

Архивные Yandex/checklist/recovery материалы содержат old provider/fallback и SMTP production-test. Они уже снабжены архивными предупреждениями; фактические прошлые команды сохранены в историческом контексте. Старый Windows BAT содержит reset --hard и pnpm, не запускается. Текущие DEPLOYMENT/README явно запрещают применять его. Действующие Mail.ru/DEPLOYMENT команды setup/restart допускаются только после отдельного разрешения, в аудите не выполнялись.

Найдены и исправлены только документальные противоречия DOC-01: COMPONENT_MAP, текущая видимость исключения LexRadar в style docs, явное разделение контрактов двух API, факт завершённого релиза в PROJECT_STATUS. Не утверждаем идентичность GitHub и VPS. Текст политики public/privacy.md относится к приложению, поэтому не редактировался даже как Markdown.

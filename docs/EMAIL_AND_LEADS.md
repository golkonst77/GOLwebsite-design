# Формы и доставка писем

## LexRadar

```text
/lexradar → components/lexradar-form.tsx → POST /api/lexradar
          → lib/lexradar-handler.ts → lib/email-service.ts
          → Nodemailer / Mail.ru SMTP → рабочий ящик → ручное рассмотрение
```

Обязательны URL сайта, имя, email и согласие; телефон и комментарий необязательны. Валидация на сервере: `lib/lexradar-validation.ts`. В запросе также UUID заявки, версия согласия, honeypot company и допустимые UTM. В письмо входят идентификатор, данные формы и отметка версии/времени согласия. Пользовательский email применяется как Reply-To, а не как SMTP_FROM.

Проверяются enabled/ready, точный Origin, тип JSON, размер тела до 16 KiB, время чтения, schema и honeypot. Лимит — 5 попыток за 10 минут; без доверенного адреса используется общий bucket процесса. Повтор одного requestId с теми же данными использует сохранённый результат в течение 30 минут; изменённые данные дают 409. Состояние in-memory, сбрасывается при рестарте; distributed exactly-once не гарантируется.

| HTTP / code | Значение |
|---|---|
| 200 ACCEPTED | SMTP принял письмо для нужного получателя, без rejected recipients |
| 400 VALIDATION / INVALID_BODY / CLIENT_ADDRESS | Невалидные данные, тело либо доверенный адрес |
| 403 ORIGIN | Домен отправки не совпадает с разрешённым |
| 409 REQUEST_CHANGED | Изменены данные прежнего requestId |
| 413 BODY_SIZE / 415 CONTENT_TYPE | Неверный размер или формат запроса |
| 429 RATE_LIMIT | Подождать окно лимита; не отключать защиту |
| 502 SEND_FAILED | Определённая ошибка отправки |
| 503 UNAVAILABLE | Форма выключена, не готова или исчерпана ёмкость |
| 504 DELIVERY_UNCONFIRMED | Результат неопределён; письмо могло быть принято |

Успех отображается только после SMTP acceptance, но не доказывает попадание во входящие. При ошибке данные формы сохраняются и доступен альтернативный email. Автоматического аудита и автоматического ответа клиенту нет. Юридические ссылки `/privacy` и `/lexradar/consent` сохранены.

## Общая форма сайта

`components/lead-form.tsx` → POST `/api/lead` → тот же email-service. Контакт здесь — телефон, а не email LexRadar. Действуют отдельные проверки имени, телефона, согласия, honeypot и свой limiter. Не переносить JSON/лимиты одной формы на другую. Точный контракт — `app/api/lead/route.ts` и тесты.

## Подтверждённая доставка

Переход с Яндекса на Mail.ru включён через PR #7; отправка и получение используют единый рабочий ящик golwebstudio@bk.ru. Владелец подтвердил 17.10.2026 реальное получение заявки, отправленной через публичную форму. Это ручное подтверждение, не результат mocks и не повторная отправка из Codex.

## Ограничения

Limiter и результаты повторных запросов in-memory: перезапуск сбрасывает состояние. single-process допустим лишь для одного процесса; для нескольких нужен реальный общий ingress-limit. SMTP acceptance не гарантирует inbox; результат доставки подтверждается отдельно. На новых установках форма закрыта.

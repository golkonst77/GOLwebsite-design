# Mail.ru: golwebstudio@bk.ru

Это текущая инструкция, заменяющая прежние инструкции Яндекса. Код по умолчанию не включает форму. Production в рамках подготовки PR не менялся.

## После отдельного разрешения на развёртывание

Развернуть этот PR штатно, сохраняя LEXRADAR_FORM_ENABLED=false. Используются Node 24, существующие Nodemailer/@next/env/tsx и Python 3 из Ubuntu. Новые npm-зависимости, почтовые сервисы, конфигурация Nginx и автоматический аудит не добавляются.

Под пользователем, владеющим файлами сайта, в интерактивном терминале:

~~~sh
cd /var/www/golwebstudio && npm run smtp:setup
~~~

Сам запуск этой команды является отдельной production-операцией. Скрипт сначала показывает область изменения и требует ввести НАСТРОИТЬ; без подтверждения ничего не записывает. Пароль приложения Mail.ru вводится через getpass без отображения. Если безопасный TTY недоступен, скрипт прекращает работу; пароль не читается обычным input, аргументом команды или из истории.

Будут установлены:

~~~dotenv
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_AUTH_METHOD=LOGIN
SMTP_USER=golwebstudio@bk.ru
SMTP_FROM=golwebstudio@bk.ru
MAIL_TO=golwebstudio@bk.ru
SMTP_PASS=
LEXRADAR_FORM_ENABLED=false
~~~

Пустая строка SMTP_PASS выше — только шаблон; реальное значение скрипт получает интерактивно.

## Очистка и сохранность конфигурации

Из .env.production.local, .env.local, .env.production и .env удаляются только активные определения известных SMTP_* (HOST, PORT, SECURE, AUTH_METHOD, USER, PASS, PASSWORD, FROM), YANDEX_EMAIL/YANDEX_PASSWORD, MAIL_TO/LEAD_TO_EMAIL и LEXRADAR_FORM_ENABLED. Новая единственная конфигурация записывается в .env.local. Остальные строки, комментарии и многострочные значения сохраняются; похожий текст внутри другой переменной не удаляется.

Файлы заменяются атомарно, с правами 600; временные файлы тоже 600 и удаляются. Пароль не сохраняется в резервных копиях, Git, логах, отчётах, argv или внешних сервисах. Представление пароля экранируется для Next; перед записью проверяется точное совпадение через установленный @next/env в локальном subprocess. Значение передаётся ему только в памяти через stdin; вывод — только статус.

Если обнаружены symlink/hardlink env-файлы, другой владелец, неоднозначные кавычки, изменение файлов во время настройки или отслеживаемый Git .env.local, операция прекращается до небезопасной перезаписи. При частичной ошибке записи выполняется откат собственных изменений без перезаписи параллельных правок оператора.

Скрипт не меняет окружение существующего PM2. Если SMTP/YANDEX/MAIL_TO/LEAD_TO_EMAIL/флаг формы уже экспортированы в окружение команды, он отказывается работать и печатает только имена конфликтующих ключей. Удалить устаревшие значения нужно в согласованном источнике конфигурации службы, не публикуя pm2 env/dump и не меняя инфраструктуру без разрешения. Простой --update-env не гарантирует удаления всех старых ключей.

## Реальная проверка и включение

После записи скрипт запускает существующую диагностику с реальными настройками:

~~~sh
cd /var/www/golwebstudio && npm run smtp:diagnose -- --production-test
~~~

Она проверяет дубликаты и точную цель Mail.ru, TLS/сертификат, авторизацию, затем отправляет одно настоящее синтетическое письмо на golwebstudio@bk.ru. Требуются SMTP_AUTH_OK, SMTP_ACCEPTED и DIAGNOSTIC_OK. Секреты и сырые ответы SMTP не выводятся. Подтверждение SMTP не доказывает поступление во входящие.

После успешной команды скрипт попросит найти письмо с Test ID в golwebstudio@bk.ru, включая спам. Только после фактического получения ввести ПОЛУЧЕНО. Enter, ошибка SMTP, неопределённая доставка или отсутствие готовых origin/настроек защиты оставляют форму выключенной.

LEXRADAR_FORM_ENABLED=true записывается только при всех трёх условиях: успешный реальный SMTP-тест, явное подтверждение получения владельцем, getLexradarConfig().ready. Никакого автоматического подтверждения ящика нет.

Настройки LEXRADAR_SITE_ORIGIN и защиты от спама сохраняются. При одном Node-процессе допустим ранее настроенный single-process; для нескольких workers нужен проверенный общий edge-limit. Скрипт не выбирает этот режим наугад и не меняет Nginx.

PM2 не перезапускается автоматически. После отдельного разрешения оператор применяет обновлённую конфигурацию службы и штатно перезапускает сайт, убедившись, что старое окружение не перекрывает файл. Затем отправляет одну TEST заявку через /lexradar и проверяет получение письма. При сбое вернуть флаг false и штатно применить настройку.

Все публичные резервные контакты и контакт для отзыва согласия теперь golwebstudio@bk.ru; ссылки /privacy и /lexradar/consent сохранены. Версия согласия повышена из-за изменения контактного адреса. Поля, дизайн, валидация, rate limit, honeypot и ручное рассмотрение заявок сохранены.

# Mail.ru SMTP: настройка и включение LexRadar

Единственная актуальная почтовая инструкция. Яндекс и прежний IPv6 fallback не используются. Пароль приложения и значения серверного окружения в документацию не копировать. [Имена переменных и условия готовности](ENVIRONMENT.md).

## Действующий сайт

Владелец уже подтвердил SMTP_AUTH_OK, SMTP_ACCEPTED, получение контрольного письма, а затем получение настоящей заявки из формы. Ради обновления документации не запускать установщик и повторные тестовые письма. Не менять рабочие настройки и не перезапускать production без отдельного разрешения.

## Новая установка или отдельно разрешённая перенастройка

1. Развернуть проверенный код с выключенной формой. Подготовить корректный LEXRADAR_SITE_ORIGIN и режим защиты, соответствующий числу процессов/реальному ingress-limit.
2. В интерактивном SSH-терминале под владельцем файлов сайта, из каталога приложения, выполнить `npm run smtp:setup` с Node 24 в PATH.
3. Установщик покажет область изменений и запросит явное подтверждение. Пароль вводится скрыто через getpass; не передавать его в аргументах, истории, сообщениях или скриншотах.
4. Установщик оставляет единственную SMTP-конфигурацию в `.env.local`, устраняет известные старые определения в production env-файлах, сохраняет другие настройки и задаёт форму false. Файлы заменяются атомарно с правами 600. Значение пароля проверяется через Next loader без вывода.
5. Установщик выполняет реальную авторизацию и отправляет одно контрольное письмо. SMTP_ACCEPTED означает принятие сервером, а не проверку входящих. Только после фактического получения нужного Test ID владелец вводит ПОЛУЧЕНО.
6. Форма может включиться только после успешного SMTP-теста, подтверждения владельца и getLexradarConfig().ready. Установщик не перезапускает PM2/Nginx и не выбирает режим защиты самостоятельно.

При FORM_NOT_READY_CHECK_ORIGIN_AND_ABUSE_CONFIG_FORM_LEFT_DISABLED исправить origin/защиту по ENVIRONMENT. Если письмо уже подтверждено, повторная SMTP-отправка ради исправления этих настроек не нужна. Проверить ready, затем установить LEXRADAR_FORM_ENABLED в строчное true и штатно применить настройку после разрешения.

## Диагностика по необходимости

Из каталога приложения с Node 24 в PATH:

```sh
npm run smtp:diagnose
```

Без флагов — только инспекция конфигурации, без сети/писем. `-- --verify` проверяет соединение и авторизацию без письма. `-- --production-test` отправляет одно настоящее контрольное письмо и используется только при явно разрешённой проверке. Не запускать сетевые режимы автоматически при чтении документации или сборке.

Вывод содержит безопасные статусы и коды, а не сырые SMTP-ответы/пароли. SMTP не может подтвердить реальное прочтение/поступление во входящие: это делает владелец.

Экспортированные переменные процесса имеют приоритет над файлами. Установщик отказывается работать при унаследованных конфликтующих ключах; `pm2 restart --update-env` не гарантирует удаления старых ключей. Не публиковать pm2 env/jlist/dump или содержимое env-файлов. [Диагностика](TROUBLESHOOTING.md).

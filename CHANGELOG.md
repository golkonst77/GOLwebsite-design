# История изменений

## 1.3.1 — 2026-10-17

Выпуск фиксирует запуск реального приёма заявок LexRadar и приводит документацию в соответствие с уже включёнными в main изменениями. Поведение приложения и дизайн при оформлении выпуска не меняются.

### Сохранённые изменения после исходной 1.3.0

- Универсальная SMTP-конфигурация, безопасная диагностика и обработка подтверждения SMTP — PR #4.
- Переход с Яндекса на Mail.ru, единый почтовый ящик отправки/получения golwebstudio@bk.ru, удаление старого fallback — PR #7.
- Интерактивный установщик с вводом пароля без отображения, устранением конфликтов старых определений и сохранением других настроек.
- Серверная проверка обязательных полей и согласия, Origin, honeypot, ограничения запросов и размера тела, обработка ошибок и повторов.
- Успех только после принятия письма SMTP-сервером; при ошибке — безопасное сообщение и альтернативный email.
- Сохранены дизайн и юридические ссылки; заявки рассматриваются вручную.

### Оформление контрольной версии

- Согласованы package.json и package-lock.json, добавлены CHANGELOG, инструкции выпуска и восстановления.
- Обновлены README, индекс документации, статус, описание почты, окружения и диагностики.
- Исторические материалы отмечены как архивные; опасные старые команды не являются текущей инструкцией.
- Добавлено исключение локальных логов и резервных копий из новых Git-коммитов.
- Публикация тега и GitHub Release выполняется только после успешных CI-проверок точного коммита main; VPS не затрагивается.

### Подтверждение

Владелец 17.10.2026 подтвердил успешную production-сборку, включение формы, отправку заявки через сайт и получение соответствующего письма во входящих. Это ручная проверка владельца; CI не обращается к production SMTP. Git SHA серверных исходников отдельно не подтверждён.

## 1.3.0 — до оформления 1.3.1

Предыдущая версия package.json; этапы внедрения и доводки LexRadar описаны в исторических отчётах `docs/lexradar-*`. PR #2, #3, #4 и #7 уже включены в main; номер пакета при этих изменениях оставался 1.3.0. Не предполагает существования опубликованного тега v1.3.0.
